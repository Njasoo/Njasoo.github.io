# TCP/IP
是一个面向连接，可进行可靠传输的协议<br>
过程就是三次握手，握手过程就是，客户端发送请求连接，服务器收到之后返回一个ack，然后客户端再返回ack

然后还会通过序号、重传、滑动窗口这些机制来实现可靠传输

# UDP
不可靠传输，没有连接，直接传输，游戏这种比较关注数据传输时延的可能用UDP用的比较多

# HTTP
HTTP1.0是短连接，每次请求都要独立建立一次TCP连接，
HTTP1.1多了持久连接，一个TCP连接可以处理多个请求，HTTP2有多路复用，一个TCP连接也可以处理多个请求，但是1.1是串行的，这个是并行的

# websocket
是基于TCP的一个协议，是长连接，全双工的，客户端和服务器都可以同时发送信息，就很适合实时交互的场景

# pinia
用defineStore来定义一个store，state是定义属性的地方，getter是获取通过state计算得到的一些值，actions就是对state的属性进行一些更改

和props/emit最大的区别就是，props/emit是父子组件之间数据的传递，pinia的store可以在任意组件之间传，然后还支持数据的持久化

为什么不全部用store，props/emit这些可能清晰地表达了数据之间的依赖关系，而store就是一堆全局数据的集合，你看不出来具体数据是被哪个组件以来，写起来就比较混乱

和vuex的区别，pinia可以更好地支持组合式的api，然后现在vuex官方也宣布说不再更新，后续都是用pinia的，所以就转为用pinia了

# vue2和vue3的区别
vue3支持组合式api，vue2是选项式api

# 性能优化
分页设计，比如显示列表的时候，没必要全部显示。懒加载，就是需要这个组件的时候再加载，用computed缓存计算结果，避免重复的计算

# Promise
有什么状态？pending，fulfilled（成功），rejected（异步操作失败）。常用的接口？then（回调），catch（捕获异常），finally（失败与否都要执行的东西）

# localStorage、sessionStorage、indexedDB的区别
localstorage是永久保存的，sessionstorage是便签页关闭就没了，indexedDB也是永久，用来存大的复杂的数据

# https和http
https就是http+s，s就是加密传输，登录、支付这些都一定要用https
