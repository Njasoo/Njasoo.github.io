tailwind css 的设计思想就是用类名来写 css，每个类名提供一个原子化的操作，这样我们开发者就不用去烦恼类名应该要写什么，类名即功能，另外就是开发速度也比较快，因为 tailwind 的类名通常都很简短，然后听过 tailwind UI 就是自己开发的一个基于 tailwind css 的组件库
