# 动态加载路由

也许是为了避免二级路由嵌套太多层吧, 可以使用动态加载路由的方法来避免嵌套, 当登录后再加载路由, 可以通过vuex或者pinia维护一个全局变量, 配合路由守卫, 判断是否已经登录过, 如果登陆过就就直接放行, 否则就加载新的路由, 然后再放行, 这里的next就要指定路径了



# pinia的持久化存储

pinia在页面刷新的时候会重新初始化store的属性, 导致全局变量内容丢失, 可以通过安装插件来改变pinia的存储方式, 使得数据的存储变成持久化的, 也就是说刷新之后仍能保持不变

```bash
npm install pinia-plugin-persistedstate
```

# 跨域请求

前端访问后端接口的时候, 如果没有配置好跨域请求的部分会被block, 最标准的解决方案是在后端设置响应头, 指定哪些域名是可以访问到这些借口的

或者前端在开发环境下使用代理服务器
