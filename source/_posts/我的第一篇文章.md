# 部署命令
### 清理之前生成的缓存文件和静态文件

```bash
$ hexo clean
```

静态文件包括以下两个文件：

- ./public/
- ./.deploy_git/

缓存文件则是：

- ./cache/

### 本地生成静态文件

```bash
$ hexo g
```

### 本地预览页面

```bash
$ hexo s
```

### 部署页面到github pages服务

```bash
$ hexo d
```

# 主题更换

主题在**_config.yml**里面更改theme属性

如果在更改主题之后，发现页面部署失败的话，可能是因为有部分主题使用了Pug模板引擎，而本地项目还没有安装相关插件

可以通过以下命令安装：

```bash
$ npm install hexo-renderer-pug hexo-renderer-stylus --save
```
