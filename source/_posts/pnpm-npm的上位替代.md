听说 pnpm 是能够在不同的项目之间共享依赖，不会重复安装相同的包，那可以说这个工具还真是解决了我一直以来的困扰，每次创建一个新的项目，就要重新安装一次 axios 和 vue-router 这种每次都要用到的依赖，空间浪费的太多，不知道什么时候我的电脑磁盘就会被填满，但是有这个 pnpm 的话，问题就解决了，下面说一下怎么安装这个玩意

```bash
npm install -g pnpm
```

这样就安装成功了

然后检查一下是否安装成功

```bash
pnpm -v
```

后续在项目里面要用 npm 的地方都用 pnpm 替代就行

听说 pnpm 创建的 node_modules 结构和 npm 创建的不太一样，后续要注意一下，但是不是一个很大的问题
