# 全局安装vue

```(空)
npm install -g @vue/cli
```

# express-generator后端项目基础骨架

```(空)
npm install -g express-generator
```

**安装后端框架**

```(空)
express --view=ejs server
```

express --view=ejs server 命令的作用是使用 Express 应用生成器 创建一个基于 EJS 模板引擎 的 Express.js 项目，项目目录名为 server
