# 最推荐选的 Top5

1. 基于 WebSocket 的聊天系统设计（72）
   → 你可以直接在现有聊天室项目上扩展成正式毕设。

2. 基于二维码的课堂考勤系统（117）
   → 简单、逻辑清晰、功能可展示。

3. 基于 AI 的个人行为智能日记系统（50）
   → 可结合 ChatGPT API，带点 AI 亮点。

4. 基于课件的智能复习系统（135）
   → React 前端 + Django 后台 + 题库，完整可交互。

5. 旅游拼团微信小程序设计与开发（226）
   → 适合前后端分离练习，可展示 UI 和交互。
