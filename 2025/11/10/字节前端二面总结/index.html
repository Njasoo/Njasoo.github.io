字节前端二面总结

Created2025-11-10|Updated2025-11-11
|Post Views:

这次的面试感觉表现的非常差，其实就是我的方向错了，我老是专注于应用这一方面，但是面试的时候主要问的是原理，其实也是非常地有道理，毕竟如果只会应用的话，和培训班就是没有区别的，但是其实科班人员写工程代码，也不会比培训班的人好到哪里去

我回忆一下今天面试问了什么，那些我答出来的就不写了

  1. 在浏览器输入 url 之后按下回车键发生了什么 按下了回车键之后，首先会通过 DNS 协议来从域名解析出目标服务器的 IP 地址，获取到这个 IP 地址之后，会通过 TCP 三次握手来建立连接，然后就可以开始发送 HTTP 请求了，然后服务器会根据请求的内容返回响应的信息，同时浏览器会根据返回的数据类型进行不同的解析，下面具体说一下渲染的过程，首先会解析 html 生成 DOM 树，然后再解析 CSS 生成 CSSOM，然后将这两部分合并成 render tree，然后就可以进行布局以及绘制

    顺便要说一下关键点，比如说解析 html 的时候，碰到了 script 标签，会先停止解析，选择先去执行 js，因为 js 可能会改变 DOM 的结构，js 是没有相关的树的，只是执行里面的逻辑而已

    顺便再说一下，这个解析 html 树的过程是自上而下的

  2. vue3 的生命周期 说实话这个真不应该不懂的，哎，但是做项目的时候确实没有用到，感觉所谓自顶向下的学习方法也是有点问题的啊，就是知识面会过于偏向应用，过于偏向应用有什么问题呢，好像又没有什么问题，但是有很多只是吧，是需要先知道的前提下才有意识去用，搞不懂呢

    然后面试官首先问的是 setup 这个周期，干的一些事情吧，我先按照文档的顺序解释一下，每个生命周期吧

    首先是这个 onMounted，作用就是注册一个回调函数，然后在组件挂载完成之后执行的一个逻辑，那么什么情况下一个组件称之为挂载完成呢，所有的同步子组件已经被挂载，自身的 DOM 树已经创建完成并且被插入到父容器当中，简单地说一下什么是同步子组件，什么是异步子组件吧，同步子组件就是立即加载，然后异步子组件就是用到的时候才加载，更进一步的解释感觉真没有必要了，反正都是八股文而已

    第二，onUpdated，也是注册一个回调函数，在响应式状态发生改变从而导致 DOM 树也发生改变之后会调用

    第三，onUnmounted，在组件被卸载的时候调用，什么叫做卸载，就是他的所有子组件都已经被卸载，以及他的所有相关的响应式作用都已经停止，这么解释完之后其实还是不太懂，要举几个具体的例子，比如说 v-if，当这个布尔表达式为 false 的时候，相关组件就会被卸载，还有就是页面跳转的时候，从 Home.vue 跳转到 About.vue，Home.vue 也会被卸载，具体的例子就是这样

    onBeforeMount，组件挂载之前调用，在这个生命周期，组件的响应式状态已经被设置，但是相关的 DOM 还没有被创建

    onBeforeUpdate，在这个时候，组件的响应式状态已经发生了改变，但是 DOM 还没有被正式更改

    onBeforeUnmount，组件被卸载之前调用

  3. 有没有用过 keep alive 我甚至都不知道这是一个什么玩意，连辩解的地步都没有，只能说自己不会了

    这个就不在这里作答了，这好像是一个比较庞大的一个知识点，所以要系统地去学习

  4. setup 是什么，了解吗 我的回答是不了解，完全不会啊

    setup 在生命周期里面是最先的，在 onBeforeMount 前面，所以总结一下吧，vue3 生命周期的顺序就是 setup, onBeforeMount, onMounted, onBeforeUpdate, onUpdated, onBeforeUnmount, onUnmounted

    setup 是 vue3 的入口函数，主要的作用就是定义响应式数据，方法，计算属性，侦听器还有生命周期钩子，然后因为在 setup 这个周期，组件没有被挂载，所以是没有 this 能用的，script setup 是 setup 的语法糖，然后就不需要写 export default 和 return 这些语句，感觉回答这些就行了，毕竟实际上使用的时候都是直接用语法糖的

  5. 有一个商城，我要显示 top10 的信息，但是数据量非常地大，内存无法全部放下，应该怎么取到这个 top10 这道题其实我的大致思路是正确的，但是有些地方我有点不冷静，脑筋没转过来

    这道题蛮奇怪的，说是一道算法题，其实根本就不是常规的算法题，我一开始还以为这是一道大数据的算法题，一开始我的思路很混乱，说什么分成 10 台主机去存这个数据，然后每台主机去取出 top1 的数据，然后我发现这不对啊，其实每台主机取 top10 就行了，至于怎么取，肯定是优先队列吧，另外再优化一下回答，不是分成十台主机，而是分成若干台主机使得每台主机能把被分割之后的数据存到内存里面，然后每台主机取 top10 的数据，然后这些数据再取一次 top10 就行了，然后我还跟面试官说什么，感觉这不是算法优化，这是在堆硬件，但是感觉我的大致思想是说对了，应该算是我过了，另外我也说了二叉堆的原理，哎果然打算法竞赛的还是要懂原理的啊，还好我到现在都还记得怎么手撸二叉堆，不是白学的

  6. 在实习当中期望的工作内容是什么 这题好笼统好抽象啊，纯纯凑数的吧，感觉就是在预示着我即将被淘汰，我不应该话太多篇章在这话题上面的，我说了什么希望组内的氛围好一点，然后工作量不要太严重，然后人际关系希望能够和谐一点之类的，感觉完全没有说出一些积极方面的东西，答得也是非常地差

    对的对的，我在回答的时候不应该说这么多工作氛围的事情的，应该说多一点自己希望接触到什么技术，就说自己想要接触到项目工程化和性能优化的内容这样，因为这些在个人项目当中是比较难接触到的，个人项目都是比较小型的项目，所以说性能优化和工程化没有那么重要，反而会影响到开发效率，但是在庞大的项目当中，性能优化就体现得很明显，而多人合作的大项目也更加需要工程化的思想
