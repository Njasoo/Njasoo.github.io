console.log 在服务端和客户端的区别

首先说一下如果一个文件顶部写了”use server”的话, 那么里面所有的函数都默认带上了 use server

在服务端的 log 会打印到控制台, 客户端的会打印到浏览器

zod 数据类型校验

omit 是删除这两个字段的意思, true 只是删除确认, 没有特别含义

revalidatePath
