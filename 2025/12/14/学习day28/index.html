使用 setstate 函数的时候, 要放在 useEffect 里面

不然会死循环, setState 函数, 改变了 state 的值, 导致组件的重新渲染, 然后导致重新请求

一个放在 useEffect 里面的 setState 的例子

这段代码肯定是不能放在 useEffect 里面的, 不然这个请求就只能发生一次了, 而这里的 setCurrentUsername 确实导致了组件的重新渲染, 只不过是我没有发现而已, 首先是它跳转了, 其次是它就算没有跳转, 也不会陷入死循环, 要我手动触发 button 的 submit 事件才会触发

zustand 的属性需要时间来初始化

我必须要让它不停地重复执行, 直到 currentUsername 加载了出来, 这个点太坑了

其实正确做法应该是后端根据 token 存用户信息, 然后前端在加载的时候通过 token 请求 username, 不应该存在 zustand 的, 但是这里先这么干
