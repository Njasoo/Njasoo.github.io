TokenObtainPairView 会自动使用 django 自带的 user, 进行登录逻辑, 所以这个就是登录接口

TokenObtainPairView 传入的数据和 serializer 定义的一样, 传入 username 和 password 就行了, 然后会返回 access 和 refresh 两个 token, refresh 是用来访问 refresh 这个接口的, 这个接口重新返回一个 access token

JWT

全称为 json web token
是一种开发标准, 规范

JWT 是一种前后端交互的方式, 就是登录接口生成 token 返回给前端,前端存在 localstorage 里面,然后每次申请接口的时候都要带上 token,后端再验证 token 的这么一个流程

JWT 其实指的是 token 的三段格式
这个 token 每部分都是 base64URL 的编码格式
Header,Payload,Signature

头部是根据选择的加密算法编码而成
载荷是根据数据来编码生成
签名是根据头部载荷还有密钥来生成的,有点像校验码,就是校验码吧

要搞这些的话查一下 simple-jwt 吧
