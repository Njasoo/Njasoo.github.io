时序知识图谱

任务画像分类

  1. 行为模式分类 (Behavioral Patterns) 核心逻辑：分析行为节点在时间轴上的分布密度和一致性。 从图谱提取的特征： 行为频率 ( f f )：一段时间内 Behavior 节点（如健身、加班）的总数。 时序熵 ( H H )：计算行为节点发生时间点的分布。如果时间点非常固定（比如每天 8 点），熵值就很低。 社交关联度 ( d d )：行为节点与 Person 节点相连的边占总边数的比例。 输入分类器的向量：[总频率, 时间方差, 社交占比] 三类标签判定： 自律型：频率高，时间方差极低（生活极其规律）。 社交活跃型：社交占比高，行为节点多与他人关联。 散漫/被动型：频率低，时间分布完全随机。
  2. 思维模式分类 (Thinking Patterns) 核心逻辑：分析图谱中的因果链条（Causality Chains）。即遇到“问题节点”后，后续连向了什么。 从图谱提取的特征： 正向解决路径比：统计 问题节点 → → 尝试行为 → → 积极情绪 这类路径的占比。 负面反馈循环比：统计 问题节点 → → 消极情绪 → → 无后续行为 这类死循环的占比。 归因中心度：分析“我”这个节点连向“自责/内部原因”多，还是“环境/外部原因”多。 输入分类器的向量：[解决路径数, 循环路径数, 归因得分] 三类标签判定： 成长型思维：正向解决路径占据主导，遇到问题倾向于产生行为节点。 固定/消极型：负面反馈循环多，遇到问题节点后直接触发消极情绪。 回避型思维：问题节点后紧跟的是与问题无关的“娱乐/逃避行为”节点。
  3. 情感模式分类 (Emotional Patterns) 核心逻辑：基于图谱中 Emotion 属性的时序统计特征。 从图谱提取的特征： 情感均值 ( μ μ )：过去一段时间情绪得分的平均水平。 情绪波动率 ( σ σ )：得分的标准差（反映情绪是否稳定）。 突变系数 ( k k )：情感分值斜率（Slope）发生剧烈正负反转的频率。 输入分类器的向量：[均值, 标准差, 突变次数] 三类标签判定： 平和稳定型：均值中等偏上，标准差极低。 情绪敏感型：突变系数高，标准差大（极易受外界影响大喜大悲）。 慢性压抑型：均值长期处于负值区间，且波动率极小（即你之前提到的低位水平线）。
  4. 艺术审美分类 (Aesthetic Preference) 核心逻辑：基于图谱中“审美实体”的语义聚类（Clustering）。 从图谱提取的特征： 领域命中率：统计日记中提到的实体节点属于哪些语义簇（如：古典音乐、赛博朋克、印象派、自然风光）。 审美深度：单一领域节点的重复出现频率。 输入分类器的向量：[古典艺术分, 流行文化分, 自然主义分, 科技美学分] 三类标签判定： 古典主义者：节点集中在传统艺术、经典音乐、历史古迹等语义范畴。 科技先锋派：节点多为科幻、数码、代码、电子音乐。 自然/极简主义：节点多为户外、徒步、天气、简约生活等描述。

  1. 最终的“降维打击”方案：基于词性熵的通用校准 为了不再折腾，我们要采用一个在学术上最通用、逻辑上最简单的方案：“没形容词就没情感”。 不论是鲁迅还是现代人，写“下雨”、“吃面”、“写代码”都是事实陈述（名词和动词多）；而“开心”、“痛苦”、“太慢”才是情感表达（形容词和副词多）。 请彻底替换 backend/diary/nlp_utils.py 为这个版本： code Python import jieba.posseg as pseg from snownlp import SnowNLP

def get_sentiment(self, text):
    """
    通用逻辑：基于词性权重的概率修正算法
    """
    if not text.strip(): return 0.0

    # 1. 基础概率 (0~1)
    s = SnowNLP(text)
    raw_prob = s.sentiments

    # 2. 提取语言学特征
    words = list(pseg.cut(text))

    # 统计核心词性
    # a: 形容词, d: 副词, e: 叹词, y: 语气词
    subjective_words = [w for w, f in words if f.startswith('a') or f.startswith('d') or f in ['e', 'y']]
    # n: 名词, v: 动词
    factual_words = [w for w, f in words if f.startswith('n') or f.startswith('v')]

    # 3. 【核心通用逻辑】：计算主观权重 (Confidence)
    # 如果句子里全是名词动词（陈述事实），我们就对 SnowNLP 的结果“极其不信任”
    # 如果句子里出现了形容词，我们才认为情感分有价值
    sub_weight = len(subjective_words) / len(words) if len(words) > 0 else 0

    # 4. 情感中心化
    # x 范围 [-1, 1]
    x = (raw_prob - 0.5) * 2

    # 5. 【数学修正】：线性压缩 + 主观加权
    # 如果没有形容词，sub_weight 是 0，最终得分就是 0。
    # 如果有 1-2 个形容词，sub_weight 会在 0.2~0.4 之间，情感会被保留一部分。
    # 这样“无事”、“下雨”这种纯事实陈述会由于没有形容词而强制归零。
    score = x * sub_weight * 2.0 # 2.0 是增益系数，补偿压缩

    # 6. 逻辑补丁：处理否定词 (不, 没)
    if any(nw in text for nw in ["不", "没", "无", "非", "别"]):
        if score > 0: score = -abs(score) # 强行翻转极性

    # 7. 最终裁定
    final_score = round(max(min(score, 1.0), -1.0), 2)

    # 极小值过滤 (Dead Zone)
    if abs(final_score) < 0.1:
        return 0.0

    return final_score

def extract_graph_data(self, text):
    words = list(pseg.cut(text))
    entities = []
    behaviors = []
    for word, flag in words:
        if flag in ["nr", "ns", "nt", "nz"]:
            entities.append({"name": word, "label": flag})
        if flag in ["v", "vn"] and len(word) > 1:
            behaviors.append(word)

    return {
        "entities": entities,
        "behaviors": list(set(behaviors)),
        "sentiment_score": self.get_sentiment(text),
    }
