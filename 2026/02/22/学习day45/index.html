牛客2026年除夕娱乐赛

B

题目链接:https://ac.nowcoder.com/acm/contest/127676/B

思路:分两种情况

下面证明当且仅当哥德巴赫猜想成立时成立

  1. n是偶数 则存在质数p,q使得p+q=n

如果gcd(p,n)==1

0,p,2p,3p,…,(n-1)p,每个都mod n

最后得到的每一个数,将没有重复,这n个数字构成一个模n的完全剩余系,就是{0,1,2,…,n-1}这个集合

每个数都+1,将会得到合法的排列

每个数字之间的差值要么是p,mod n的操作相当于+p-n=-q,也是质数

我需要证明,为什么不会重复

前提: gcd (p, n) = 1

假设 0 ≤ i < j < n，我要证明

ip ≢ jp (mod  n)

反证法: 假设存在

ip ≡ jp (mod  n)

那么

p(j − i) ≡ 0 (mod  n)

因为 gcd (n, p) = 1

所以

(j − i) mod  n = 0

0 ≤ i < j < n

0 < j − i < n

n 不可能整除一个小于自己的正整数，所以假设不成立

所以每次+p mod n都会得到一个不一样的数字,n次之后,会得到mod n的完全剩余系

  1. n是奇数 n+1是偶数,同理可以找到质数p+q=n+1

2,4,6,…,n-p

n,n-2,…,1

1+q,1+q+2,…n-1

q=n-p+2

所以是没有问题的
