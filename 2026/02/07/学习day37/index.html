Codeforces Round 1060 (Div. 2)

C2

题意: 给定一个n, 还有长度为n的数组a和b, a是数字, b是代价, 每次可以修改一个a中的元素, 使其+1, 求使得数组当中存在gcd(a[i], a[j]) > 1的最小代价

思路: 一开始呢, 我观察到了, 最小的代价不会超过b[i] + b[j], 因为如果我指定了a[i], a[j], 想要让他们的gcd > 1, 我们分类讨论:

  • a[i] % 2 == 0 and a[j] % 2 == 0, 代价为0
  • a[i] % 2 == 1 and a[j] % 2 == 0, 代价为b[i]
  • a[i] % 2 == 1 and a[j] % 2 == 1, 代价为b[i] + b[j]

从这里我们可以发现, 如果涉及到改两个元素的操作, 最多不超过2次, 剩下的操作就是选其中一个元素使其变成某个质因数的倍数

我一开始在想, 我对于每个a_i, 我去枚举质因数, 然后计算代价, 这样是超时的, 然后我又想着说, 反过来, 我枚举每个质因数, 然后再枚举质因数的倍数, 去找最接近这个倍数的a[i], 这样的时间复杂度, 不会超过max(a) * log(max(a)) ^ 2, 但是没想到还是超时了

最后看了题解, 它是这样说的, 我们把b从小到大排序, 观察到b[1] + b[x] <= 2 * b[x], 所以选择其中一个元素, 最多也不会操作超过1次, 除了最小的那个, 所以我们只需要对于a[1]去计算到所有质因数的代价里面最小的那个就行了

Codeforces Round 1060 (Div. 2)

D

题意: 给定一个n, 有一个数组a_1, …, a_2n, 里面的元素为[1, n], 并且每个数字都出现了两次, 可以询问一个子序列, 返回结果为MAD([a_j1, a_j2, …, a_jk]), MAD就是出现了两次的元素当中, 最大的那一个元素, 叫我用不超过3n次询问, 找到数组a长什么样子

思路: 我几乎没有思路, 我一直在想, 如果我只问两个坐标, 然后返回了非零的结果, 那我就能确定这两个坐标对应的值是什么了。题解十分地简洁，假定我们有一个集合S, ask(S)的结果是0, 那么如果ask(S U i)的结果非零, 我们则知道了a_i的值, 我们逐个加入下标i, 把数组划分为两个集合S1和S2, ask(S1) = 0, ask(S2) = 0, 在分割出S1的过程当中, 已经得到了n个位置的值, 就是S2对应下标的值, 然后我们再通过往S2添加S1的某个下标, 来得到S1对应下标的值, 总共的询问次数就是2n-1 + n = 3n-1
