Codeforces Round 1061 (Div. 2)

C

题意: 有一个数组a, 你可以进行两个操作, 第一个是选择一个元素然后删掉, 第一个操作最多进行k次, 第二个操作是选择一个数x, 然后把它分解为x1, x2, x3, 其中x1 + x2 + x3 = x, x1 <= x2 <= x3, x1, x3保留, x2删掉, 问数组最大的gcd可以是多少

解法: 枚举gcd, 记为g, 然后对于ai % g != 0的元素, 考虑怎么分解, 其中一定要有两个是g的倍数, 一个尽量小, 一个尽量大, 最小的g的倍数就是g, 另外一个大的就是x - g - x % g(把余数抹掉就是g的倍数了), 那剩下的中间的数就是x % g, 但是x % g < g, 所以考虑大的数再小一点, x - 2g - x % g, 那么中间的数就是g + x % g, 它肯定大于g, 接下来我们要计算x - 2g - x % g >= g + x % g的条件, x >= 3g + 2 * (x % g), 注意到, x >= 5g的时候, 该不等式显然成立, 再仔细考虑5g > x > 4g的情况, x - x % g = 4g, 所以x - 2g - x % g = 2g, g, g + x % g, 2g, 成立, 同理, 4g > x > 3g的时候就不成立了, 所以x >= 4g的时候, 都可以分解出两个g的倍数, 所以#{x >= 4g} + #{x = g || x = 2g || x = 3g} >= n - k的时候有解
