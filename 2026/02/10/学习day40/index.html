牛客周赛 Round 130

F

题目链接: https://ac.nowcoder.com/acm/contest/127702/F

思路: 在讲解这道题之前, 我想先复习一下置换环

置换环的具体定义

置换环, 是一个有向图中的环, 我之前没有详细了解, 以为是无向图的环

置换环就是每个节点(下标)指向它应该在的位置, 对于一个排列p, i指向p[i]

对于一个环, x1 -> x2 -> … -> xn -> x1, 要拆掉这个环的方法就是

  • swap(p[x1], p[x2]) 这一步之后, p[x1]已经到了正确的位置, p[x2]的位置来到了x1, 但是p[x2]要去的位置仍是x3, 也就是说现在是x1 -> x3, 相当于只是把x2从环中拿掉
  • swap(p[x1], p[x3])
  • …
  • swap(p[x1], p[xn])

这里总共有n - 1次操作, 执行完之后, x2, x3, …, xn都从环中拿掉, 各自变成自环, 而x1也变成自环, 也就是说环中元素都到了各自正确的位置

最小交换次数

怎么证明交换次数最优就是n - 1次呢, 其实我不会严格证明, 我说一个朴素的理解吧, 首先我已经找到了一个方法, 保证每次交换能让一个元素回到正确位置, 要更优的话, 只能说是一次交换让两个元素回到了正确位置, 两个就是上限了, 因为每次交换只影响两个元素, 所以不可能说我一次交换让大于两个的元素回到正确位置, 但是如果说我一次交换让两个元素回到了正确位置, 说明这两个元素本身就是一整个环, 它们不可能在这个大的环里面, 可能我只需要证明说, 我这个让一个元素到正确位置的操作, 能保证让这个环不被拆掉, 那好像就挺显然的, 因为我要是想使得一个元素到达正确位置, 我必然是选择xi -> x{i+1}这样的一条边, 来进行交换, 这个操作我上面已经说明过, 相当于是把x{i+1}这个节点拿掉, 环的大小只是减小1, 结构没有发生大的改变, 所以n - 1次就是最优的做法

最小交换次数的公式变换

假设一个排列对应着k个环, 那么最小交换次数的计算公式就是

$$ \sum_{i = 1} ^ {k} {(size(cycle_i) - 1)} $$

其实所有的环size总和就是n, 所以公式也可以变成

n − k

如何合并环

合并环的具体操作其实就是, 从两个不同的环当中各自选择一个元素, 进行交换, 就可以合并, 下面做一个粗略的证明

假设有两个环

x1 -> x2 -> x3 -> … -> xn -> x1

y1 -> y2 -> y3 -> … -> ym -> y1

我交换p[xi]和p[yj]

交换这个操作, 实际上是交换各自的出边, 因为环中节点的值表示的是下标, 你交换两个元素, 不影响其他元素要达到的位置, 当时被交换的两个元素, 所在的下标不同了, 所以对应下标要去的位置也不同了

交换了p[xi]和p[yj], 原本xi -> x{i + 1}, yj -> y{j + 1}

现在变成了xi -> y{j + 1}, yj -> x{i + 1}

于是这个环变成

x1 -> x2 -> … -> x{i - 1} -> x_i -> y{j + 1} -> y{j + 2} -> … -> ym -> y1 -> … -> y{j - 1} -> yj -> x{i + 1} -> x_{i + 2} -> … -> xn -> x1

题目思路

好了, 搞定背景知识之后, 回到这个题目当中来, 根据题意, 我们很显然可以得到, 要使得混乱度变成2的话, 就是把排列顺序排, 然后有两个相邻的元素错位了, 现在要看所有错位的排序当中, 哪个交换次数最少, 我们遍历i和i + 1, 看i和i + 1是否在一个环当中, 如果在同一个环当中, 那么我们就留着这两个元素在环中不拿掉, 这样就比拆掉这个环的代价少1

假设使得排列有序的代价是c好了, 那么第一种情况的代价就是c-1

现在我们讨论, i和i+1不在同一个环的代价是多少, 我们先考虑一个做法, 把i和i + 1所在的两个环合并, 按照上面的说法, 我们只需要选择两个环中的元素进行交换即可, 那么代价是多少呢, 假设i所在的环size是a, i+1所在的环size是b, 合并的代价是1, 然后拆掉这个大环并保留i和i+1的代价是a+b-2, 总共的代价就是a+b-1, 原本使得排列有序的代价应该是a-1+b-1=a+b-2, 现在代价多1, 总代价就是c+1

这里我们可能会想有没有第三种可能, 使得代价是c, 也就是不变, 这个是不可能的, 我们证明一下这件事情

引理: 每次交换相邻的元素, 必然产生或减少一个逆序对, 这个很显然, 不证明了

交换任意两个元素, 逆序对的数量增减必然是奇数

考虑交换a_i, a_j

ai, a{i+1}, …, a_j

a_i一直交换到, a_j的位置是j-i次交换

之后数组变成

a{i+1}, a{i+2}, …, a_j, a_i

aj交换到a{i+1}的交换次数是j-i-1, 少了一个a_i, 其他都和a_i交换过的重叠, 所以是j-i-1

总的交换次数就是, 2*(j-i)-1, 是奇数

所以代价只可能是c-1, c+1, c-3, c+3, …, c是不可能的

代码(暴力) 思路是交换i和i+1的位置, 然后求有序的最小交换次数
