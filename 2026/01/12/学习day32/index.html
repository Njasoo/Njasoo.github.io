pnpm dev -o

这个-o 的命令就是顺便打开浏览器

复习一下 slot

slot 是一个便签, 作用是决定父组件传入插槽内容的插入位置

比如说我这里有一个 AppAlert 组件

然后父组件使用了它

父组件插入的内容就是 This is an auto-imported component.这段内容

components

在 app/components 这个文件夹底下创建的组件, 可以在其他页面自动引用, 无需 import

路由系统

app/pages 下定义路由, pages 是根目录, app.vue 也可以作为根目录, 但是最好不要这么干

可以这样操作使得 pages 下的 index.vue 作为根目录

app.vue

或者干脆直接删掉 app.vue

index.vue 就相当于 next.js 的 page.tsx

布局

在 app/layouts 里面定义布局

app/layouts/default.vue

可以看出来布局系统是通过插槽来实现的

app.vue

要通过 NuxtLayout 组件来启动布局系统

选择布局

资源存放目录

/public 这个目录是用来放 img 等静态资源的

img 这些资源放在/public/img/这个目录

在服务器上可以直接通过/img/xxx.png 来访问

样式表, 字体, SVG 这些东西放在 app/assets/这个目录底下, 这是约定速成

水合是什么东西

水合就是客户端激活的过程吧, 服务端都是静态的 html, 水合的过程就是将客户端的 js 代码和服务端的静态资源合成变成动态资源的这么一个东西

文档地址

https://nuxt.zhcndoc.com/
